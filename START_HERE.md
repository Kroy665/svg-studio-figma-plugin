# 👋 Start Here!

## Quick Start (3 Steps)

### 1️⃣ Install Node.js (One Time Only)
- Go to: **https://nodejs.org/**
- Click the big green button that says **"LTS"**
- Install it
- Restart your computer

### 2️⃣ Setup (One Time Only)
**On Mac:**
- Double-click `setup.sh`

**On Windows:**
- Double-click `setup.bat`

Wait 1-2 minutes until you see "Setup Complete!"

### 3️⃣ Add to Figma (One Time Only)
1. Open **Figma Desktop App** (download from figma.com if needed)
2. Click **Plugins** menu → **Development** → **Import plugin from manifest**
3. Choose the `manifest.json` file from this folder
4. Done!

---

## How to Use (Every Time)

### Start the Server
**On Mac:**
- Double-click `start-server.command`

**On Windows:**
- Double-click `start-server.bat`

**Keep this window open!**

### Use the Plugin
1. Open Figma
2. Click **Plugins** → **SVG Studio**
3. Browse, search, and insert SVG shapes!

### Stop the Server
- When done, press `Ctrl+C` in the server window

## ❓ Problems?
1. Make sure the server is running (step 1 above)
2. Make sure you're using Figma Desktop (not browser)
3. Try closing and reopening the plugin
